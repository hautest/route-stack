# 진행도 CSS 변수 {#progress-css-variable}

스택 밖의 요소(공용 헤더 등)도 전환에 맞춰 움직일 수 있습니다. 스택이 전환 진행도를 CSS 변수에 기록합니다.

```tsx
<Stack enableProgressCssVar>
  <Outlet />
</Stack>
```

```css
.header-title {
  opacity: var(--route-stack-progress, 1);
}
```

## 값 {#the-value}

`--route-stack-progress`는 전환하는 동안 `<html>`에 설정되고, 평소에는 지워집니다.

- 값은 `0`부터 `1`까지이며, 라우터가 현재 렌더하는 screen이 얼마나 들어왔는지를 나타냅니다.
- push에서는 0에서 1로 올라갑니다.
- 스와이프 백 중에는 손가락이 움직인 만큼 1에서 내려갑니다. back이 커밋되면 기준이 도착하는 screen으로 바뀌고 값은 다시 올라갑니다. 이 시점은 라우터가 그 screen의 헤더 내용을 렌더하는 순간과 같습니다.

## 비용 {#cost}

기본으로 꺼져 있습니다. 값을 기록할 때마다 루트 요소에서 상속되는 변수가 바뀌므로, 전환하는 동안 매 프레임 문서 전체의 스타일을 다시 계산합니다.

- 이 변수를 쓰는 요소가 있을 때만 켜는 것을 권합니다.
- screen 자체는 합성 스레드에서 움직이지만, 이 변수로 움직이는 요소는 메인 스레드에서 프레임당 최대 한 번 갱신됩니다. 그래서 120Hz 아이폰에서도 이 요소들은 60Hz로 움직입니다.
